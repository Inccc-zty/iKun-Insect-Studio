## 2. 用户手册（01-user-guide）

1. **安装**：整个文件夹拷贝；首次运行会建 `data/`；预读模型 30–40 秒。
2. **三步**：拖入 → 选模式/精度 → 开始；写出的 `.xmp` 在哪。
3. **界面**：左栏两行、右下缩略图墙、当前行、跟随、曝光预览开关。
4. **手动微调**：拖框/拖头点、自动重算、完成写回；失败行怎么显示。
5. **XMP 与 Lightroom**：先处理再导入 / 已导入的读元数据；三档归属策略。
6. **拼版**：6 张一排、失败格、缺图现画、分卷。
7. **训练与模型**：多目录、留出、模型下拉、导入别人的系数。
8. **恢复初始状态**：按钮 / `--reset` / bat。
9. **FAQ**：显存、没头点、裁歪、白平衡为什么不动。

图：`F02 界面分区标注图`（➕，在截图上加编号）；`F03 微调界面`（✅ 有 `_edit_mask` 类截图，重截）。

## 4. 裁切（03-crop）

1. 特征：13 项是什么、为什么只有这几类（用户的四条口径）。
2. 消融：四组单用 vs 从满配里挖掉（表格 + 柱状图）。
3. 训练口径：按批次 5 折、绝不随机分（随机分会虚高 3–8 点）。
4. 结果：IoU 中位 0.8650、≥0.8 占 73.5%、留白达标 98.8%。
5. 误差分解：换真值尺寸 +7.2 点、换真值中心 +1.3 点 → 瓶颈在尺寸。
6. 盲测 80 张：0.9017。
7. 失败案例：最差 5 张 + 原因。

## 7. 为什么色温控不住（06-white-balance）—— 必须有的一章

1. **结论先行**：只有常数 `T=5333 / Tint=+16`，MAE 163 K，中位 90 K。
2. 用户行为是地基：ΔT 对 As Shot 的回归斜率 **−1.000** → 你把相机判断完全抵消。
3. 三条走不通的路（每条都带数据和图）：
   - 掩膜内外（真掩膜 213 张）：全图 −0.288 / 掩膜内 **−0.235（最差）** / 掩膜外 −0.311；
   - 镜面高光（双色反射）：73% 有未过曝高光，`band.rg` 对 ΔT r=−0.375，**对用户设定 r=−0.040**；
   - 多特征学习（57 列 / 岭回归 + GBDT）：A 178.6 / B 181.0 / C 183.9，**全部不如常数 163.1**。
4. 方差分解：批次间 33.1% / 批次内 66.9%，识别批次也救不了三分之二。
5. 唯一的前提：拿到 RAW 线性数据（要 LibRaw 支持 Z8 HE）。
6. 边界声明：这不是"暂时没做"，是"以目前输入（内嵌 JPEG）原理上测不出来"。

图：F30 ΔT 直方图 + 常数线（➕）、F31 三条路径的误差对比（➕）、F32 散点（band.rg vs ΔT / vs 设定）（➕）。

## 10. 边界（09-limits）

- 小虫（<8% 画面宽）掩膜糊；
- 纯背面仍给"靠前"的点；
- 掩膜是量尺不是抠图；
- 换人需重拟合；
- 色温不可控（指回第 7 章）。
