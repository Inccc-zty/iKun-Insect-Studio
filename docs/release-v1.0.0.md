**Batch-process insect RAW photos: automatic crop and exposure, written as a Lightroom `.xmp` that applies on import.**

A day out shooting means one record frame per individual. In macro work the insect is always small in the frame, so the hours go into the ninety record shots — crop after crop, exposure after exposure — not the five keepers. This tool folds that into one step: drop a folder in, and every frame gets a crop box and an exposure value.

> Crop and exposure can both be wrong — nothing here is 100%. The value is not accuracy, it is turning hours of repetitive editing into minutes.

### Download

1. Get `iKunInsectStudio_v1.0.0.zip.001`, `.002` and `join-parts.bat` into one folder
2. Run `join-parts.bat` → `iKunInsectStudio_v1.0.0.zip` (2.62 GB)
3. Unzip, keep the whole folder together, double-click `iKunInsectStudio.exe`
