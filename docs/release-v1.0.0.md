**批量处理昆虫 RAW 原始照片的工具：自动裁切 + 自动曝光，写成 Lightroom 的 `.xmp`。**

外拍一天回来，每个个体都要留一张记录，但微距题材里虫子天生在画面中偏小——手持、放大倍率不够、它也不肯靠近——于是最费时间的不是那几张大片，而是剩下几十上百张的重复裁切和重复调曝光。

这个软件把这部分做成公式化的一步：拖进文件夹 → 每张出一个裁切框和一次曝光 → 结果写成同名 `.xmp`，导入图像后期软件时直接生效。

---

### 它做什么

- **裁切**：全画幅掩膜找出虫，量出「身体框」和「整体框」，105 项模型预测裁切框（留出 IoU 中位 0.865）
- **曝光**：掩膜内 / 框内背景两个亮度分位数，进一条直线给出 EV（留出 MAE 0.29 档）
- **锐化**：按光圈查表，光圈越小补得越多
- **头部修正记忆**：你手动微调过的头点会累积成经验，几何相近的照片自动照着偏

**不改**白平衡、色彩、对比、局部调整；**从不碰**原片，只写同名 `.xmp`。

> 裁切和曝光都可能出错，没有一个是 100% 准的。它的价值不是"准"，是把重复劳动从几小时压到几分钟，剩下不对的扫一眼改掉。
