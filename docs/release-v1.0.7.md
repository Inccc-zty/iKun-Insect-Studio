# iKun Insect Studio 1.0.7

## ⚠️ 先看这里：怎么从老版本更新

**这一版必须用完整包更新一次**，从 1.0.8 起才能用 80 MB 左右的小补丁。

请按三步做，**你的设置和自己训练的模型都在 `data\` 里，不要动它**：

1. 先把老目录里的 **`data\`** 整个复制到桌面（几十 MB，保险）
2. 新包解压到**另一个文件夹**，只把这两样拖进老目录覆盖：
   `iKunInsectStudio.exe`、`_internal\`
3. 启动 → 设置里确认自己训练的模型还在 → 删掉那个临时文件夹

> 1.0.6 及更早的包**没有**这个功能（只能看到新版本、不会自己下载），所以这一步需要手动做一次。
> 1.0.0–1.0.5 的包本身缺少模型（会每张失败），必须换成这一版。

## 这一版修了什么

### 1. 曝光补偿（新）

参数区多了一个「曝光补偿」：在你现有曝光模型的结果上加减，**不需要重新训练**。

- 范围 −2.0 ～ +2.0 EV，步进 0.1
- 正数更亮、负数更暗；实际写入 = 模型输出 + 补偿，夹在 ±5 EV 以内
- 改完对**之后处理**的照片生效；想立刻看到就把那张重跑一次
- 值存在 `data\config.json`，关掉软件再开还是这个数

模型本身的输出没有被改动（`ev_raw` 仍记原值），换回 0.0 就完全恢复原样。

### 2. 裁切比例：换比例不再改变虫子大小

以前换比例是“重新框一次”，虫子占比会跳。现在以**原图比例那次的结果**为基准：

```
基准面积 A₀ = 原图比例框的像素面积
换到比例 R：Pw = √(A₀·R)，Ph = √(A₀/R)
```

也就是说 3:2 换 1:1 或 16:9，**面积不变**，虫子看起来一样大，只是构图形状变了。

实测（`Z04_6394`，8256×5504）：

| 比例 | 实际像素比 | 面积 |
|---|---|---:|
| 原图比例 | 1.50 | 25.7 Mpx |
| 1:1 | 1.00 | 25.7 Mpx |
| 4:5 | 0.80 | 24.2 Mpx |
| 16:9 | 1.78 | 25.7 Mpx |

4:5 少 6%，因为竖构图装不下画幅高度，等比缩到能装下，比例仍然精确。

### 3. 固定比例不再切腿

旧算法只给「宽」加腿留白，高度由比例推出来，遇到瘦高个 + 16:9 会把腿裁掉。
现在两个方向都满足；画布实在装不下时**放弃精确比例、保住虫子**，并在结果里标记。

### 4. 成品 JPG 训练的默认比例

用成品 JPG 训练的模型，默认比例改成**照片自身的比例**，不再用模型学到的那个。
换一批成片，默认构图不会跟着漂。

### 5. 训练样本去重

同一张照片的 RAW 与 JPEG 各带一份 XMP 时，只算一个样本（RAW 优先）。
之前会被算成两张，留出指标虚高。

### 6. 对外接口

新增两个只读接口，方便外部工具查问题：

```
GET /api/logs?tail=200    → data/perf.log 最后 200 行
GET /api/errors           → 本次失败的照片与异常信息
```

### 7. 其他

- 掩膜缓存上限 4000 个文件，不再无限增长
- 配置文件改成原子写（断电不会写坏）
- 修掉 3 处文件句柄未关闭
- 发布包不再包含 `data\`（之前会把作者的设置一起发给用户）

**Mac 版首次打开**若提示“无法验证开发者”，右键点图标选「打开」，或执行一次：

```
xattr -dr com.apple.quarantine /Applications/iKunInsectStudio.app
```

包没有苹果签名，这一步只清掉 Gatekeeper 的隔离标记。**Intel Mac 跑不了**——PyTorch 已不再发布

### 精度按可用显存选

4 GB 卡选 **512**，6 GB 以上选 768。选高了不会报错，但会走系统分页，从 0.8 秒掉到 3 秒以上。
（其实作者之前试过1650 4gb也能稳定跑768，可以从高往低都试试看）
