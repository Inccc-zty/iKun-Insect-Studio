# iKun Insect Studio · 昆虫自动化后期

**昆虫微距 RAW 的自动后期**：一张照片跑一遍，得到裁切 + 曝光 + 锐化，写成 Lightroom 的 `.xmp`。
白平衡故意不碰。

> English: [README.md](README.md) · **[技术报告](docs/report.md)** · [English](docs/report.en.md)

---

## 它替你做什么

- **裁切**：全画幅掩膜找出虫，量出「身体框」和「整体框」，105 项模型预测一个正方形裁切框
  （4,184 张 / 11 批，按批次留出 IoU 中位 **0.865**）。
- **曝光**：掩膜内 p95 亮度 + 框内掩膜外 p95 亮度，两个数进一条直线；
  留出 MAE **0.29 EV**（常数基线 0.41）。
- **锐化**：按光圈严格递增（20 → 65）。

## 它明确不做什么

- **不写白平衡。** 只有常数能复现人实际干的事（ΔT 对 As Shot 的回归斜率 −1.000）。
  为什么，单独一章：`docs/06-white-balance.md`。
- **不改构图。** 不旋转、不改画幅、不重排。
- **不做抠图。** 掩膜是量尺，不是成品；红叠加只是让你确认它认对了。

## 三步

1. 下载 Release，**全部解压到同一个文件夹**。
2. 双击 `iKunInsectStudio.exe`（整个文件夹要一起留着）。
3. 把 RAW 文件夹拖进来 → 选模式 → 开始。`.xmp` 会写在照片旁边，
   Lightroom 里「从文件读取元数据」即可。

首次启动后端会预读模型（约 30 秒），这段时间可以先拖照片。

## 一张图里发生了什么

整幅缩到 768² 跑**一次** BiRefNet 分割；掩膜给出两个框（身体：开运算后最大连通块；
整体：掩膜外接矩形）。身体框外扩 15% 裁 256²，喂给自训 ResNet50 得到 64×64 热力图，
soft-argmax 取加权重心 → 一个头点。这 13 个数展开成 105 项，预测框心 x / 框心 y / 框宽；
两个亮度分位数决定曝光；光圈查表决定锐化。其它什么都不估。

## 关键数字

| 模块 | 数据 | 指标 |
|---|---|---|
| 裁切 | 4,184 拟合样本 / 11 目录 | 样本内 IoU 中位 **0.8756**，留出 **0.8650**，80 张盲测 **0.9017** |
| 裁切 · 复算 | **当前 2,280 张 / 15 目录** | 中位 **0.8172**，≥0.8 **54.2%** |
| 曝光 | 当前 2,238 行 | 留出 MAE **0.286 EV**（常数 0.404） |
| 头部 | 6 张精标 + 500 张复核 | 误差中位 **0.12 · 身体宽** |
| 白平衡 | 5,065 JPG / 2,280 RAW | 常数 T=5333/+16，MAE **163 K**（可达上限） |

> **看裁切数字要留神**：4,184 那套样本里 **56% 来自同一个目录**（`2025.7 青海`）。
> 换成当前范围内的 2,280 张（15 个目录，其中 5 个训练时没见过），同一套系数是 **0.8172**。
> 两个数都写在这里，差异的原因见 `reports/2026-11-22-rerun.md`。

## 目录

```
app/        引擎（掩膜、裁切、曝光、锐化、XMP）
ui/         桌面界面（PySide6）
skill/      算法包：脚本 + 方法笔记 + 参考文档
docs/       中英双语手册与分析报告
figures/    zh/ 与 en/ 两套图
```

权重（`head_kp_v2.pth`，95 MB）和 Windows 安装包都放在 **Release**，不进 git。

## 从源码跑

```bash
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
python run.py                 # 开发运行
python build.py               # PyInstaller 打包
```
