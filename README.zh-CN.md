# iKun Insect Studio · 昆虫自动化后期

**[使用说明](docs/manual.md)** · **[技术报告](docs/report.md)** · [English](README.md)

**一个替你做无聊重复动作的工具：找虫、定框、给曝光。**

外拍一天回来，每个个体都得留一张记录；真正值得精修的只有几张，剩下几十上百张都是"记录级"。
可微距这个题材，虫子天生就在画面里偏小——手持会晃、放大倍率不够、它也不肯让你靠近——不裁就是
"虫子缩在中间一小点"。于是最费时间的从来不是那几张大片，是剩下那几十张的重复裁切和重复调曝光。

这个软件就把这两件事做掉，结果写成同名 `.xmp`，图像后期软件直接认。

> **裁切和曝光都可能出错，没有一个是 100% 准的。** 它的价值不在"准"，在把重复劳动从几小时压到几分钟；
> 剩下不对的，扫一眼改掉就行，比从零开始裁快得多。
>
> 本软件以 **Lightroom** 和 **Adobe Camera Raw（ACR）** 为参考开发；`.xmp` 是 Adobe 的通用标准，
> Lightroom、Camera Raw、Bridge、Photoshop 读的都是同一份。



---

## 它做两件事

- **裁切**：全画幅掩膜找出虫，量出「身体框」和「整体框」，105 项模型预测裁切框的位置和边长
  （按批次留出，IoU 中位 **0.865**）。大部分能直接用，少数会偏。
- **曝光**：掩膜内 p95 亮度 + 框内掩膜外 p95 亮度，两个数进一条直线；
  留出 MAE **0.29 EV**（常数基线 0.41）。是估计值，建议当起点用。
- **锐化**：按光圈严格递增（20 → 65）。

**不改**：白平衡、色彩、对比、局部调整。**从不碰**：原片，只写同名 `.xmp`。

## 三步

1. 下载 Release，**全部解压到同一个文件夹**。
2. 双击 `iKunInsectStudio.exe`（整个文件夹要一起留着）。
3. 把 RAW 文件夹或一批照片拖进窗口 → 选模式 → 开始。
   跑完**直接导入图像后期软件**，导入时它自己会读 `.xmp`；
   如果这批早就在 Lightroom 里，才需要在那边「从文件读取元数据」一次。

首次启动后端会预读模型（约 10–20 秒），这段时间可以先拖照片。

## 一张图里发生了什么

整幅缩到 768² 跑**一次** BiRefNet 分割；掩膜给出两个框（身体：开运算后最大连通块；
整体：掩膜外接矩形）。身体框外扩 15% 裁 256²，喂给自训 ResNet50 得到 64×64 热力图，
soft-argmax 取加权重心 → 一个头点。这 13 个数展开成 105 项，预测框心 x / 框心 y / 框宽；
两个亮度分位数决定曝光；光圈查表决定锐化。其它什么都不估。

## 关键数字

| 模块 | 指标 |
|---|---|
| 裁切 | 留出 IoU 中位 **0.865**；80 张盲测 **0.902** |
| 曝光 | 留出 MAE **0.29 EV**（常数基线 0.41） |
| 头点 | 中位误差 **0.12 × 身体框宽** |
| 白平衡 | 一个常数，MAE **163 K**——这条路的最好成绩 |

指标都是留出成绩：打分用的目录，模型在拟合时没见过。

## 目录

```
app/        引擎（掩膜、裁切、曝光、锐化、XMP）
ui/         桌面界面（PySide6）
skill/      算法包：脚本 + 方法笔记 + 参考文档
docs/       中英双语手册与分析报告
figures/    zh/ 与 en/ 两套图
```

权重（`head_kp_v2.pth`，95 MB）和 Windows 安装包都放在 **Release**，不进 git。

## 从源码跑

```bash
python -m venv .venv && .venv/Scripts/activate
pip install -r requirements.txt
python run.py                 # 开发运行
python build.py               # PyInstaller 打包
```
