# 04 · 曝光（双参数）

## 1. 结论

```
EV = 3.0416 − 0.02108 · L_in − 0.01362 · L_box
```

| 符号 | 含义 | 怎么算 |
|---|---|---|
| `L_in` | **掩膜内**亮度 L\* 的 95 分位 | 掩膜按距离变换腐蚀掉边缘混色像素后取 p95 |
| `L_box` | **盒内背景**亮度 L\* 的 95 分位 | 全身外接矩形内、掩膜之外 |

| 指标 | 值 |
|---|---:|
| 样本 | 4396 张 / 11 批次 |
| 样本内 R² / MAE | 0.627 / 0.272 档 |
| 留出 MAE（按批次 5 折 × 8 次） | **0.286 档**（中位；最好一次 0.281） |
| 留出 R² | 0.577（中位；最好一次 0.596） |
| 8 次划分的范围 | MAE 0.278–0.302 / R² 0.546–0.609 |
| 常数基线（永远给 +0.33） | 0.42 档 |
| 系数比 \|主体/背景\| | 1.55 |
| 三个系数的 95%CI | 全部不含 0 |

> **口径提醒**：报"0.281 / 0.596"时要说清那是 8 次划分里最好的一次。
> 中位是 0.286 / 0.577。谁只报最好值不报中位，换个人复现就会对不上。

**这是一套"复现某个人"的系数，不是通用物理常数。换人必须重新拟合。**

## 2. 为什么是「高光 p95」

你定 EV 时看的是**高光会不会溢出**，不是画面平均亮度。

| 分位 | R² | MAE |
|---|---:|---:|
| p80 | 0.355 | 0.353 |
| p90 | 0.407 | 0.347 |
| p92 | 0.425 | 0.343 |
| **p95** | **0.443** | **0.339** |
| p97 | 0.426 | 0.343 |
| p99 | 0.370 | 0.356 |
| p99.5 | 0.323 | 0.360 |

峰就在 p95。物理解释：

- p99 以上是**镜面高光**——闪光灯打在甲壳、露珠、复眼上的反光，本来就压到 255，
  跟你提不提亮无关，是噪声；
- p80 以下是中调，离"会不会溢出"还差两档；
- p95 是"画面里最亮的那批**有结构的**高光"，正好是 EV 该守的那条线。

对照：整幅平均亮度 R² 只有 0.344，中心亮度 0.407。

**分位必须固定，不能"扫哪个最优就用哪个"**——峰很平，追最优等于拿测试集选超参。

## 3. 为什么需要第二个参数

只用 `L_in`（单参数）：MAE 0.315。加上 `L_box`：0.281–0.286。

**第二个参数的作用是「减掉背景干扰」，不是「补充信息」。**
盒内背景是紧贴主体的环境光。同样一只虫，在亮背景前和暗背景前，你给的 EV 不一样——
因为背景亮说明现场光强，主体只是没被闪到。

## 4. 测量口径（照这个做，差一点都会偏）

### 4.1 L\* 怎么算

```python
rgb = bgr[..., ::-1] / 255
lin = where(rgb <= 0.04045, rgb/12.92, ((rgb+0.055)/1.055)**2.4)
Y   = 0.2126·R + 0.7152·G + 0.0722·B
L*  = where(Y > 0.008856, 116·cbrt(Y) − 16, 903.3·Y)
```

### 4.2 掩膜内必须腐蚀

```python
dist  = cv2.distanceTransform(mask, cv2.DIST_L2, 5)
r_in  = max(1.5, 0.03 * sqrt(mask.sum()))     # 随虫子大小自适应
inner = dist >= r_in
```

小虫子腐蚀完不足 100 像素时，退到 `dist >= max(1.0, dist.max()*0.5)`。

### 4.3 盒内背景

```python
box = full 框（外接矩形）
bg  = box & (~mask)
L_box = p95(L[bg])
```

背景像素不足 50 个时（虫子占满框），这张的 `L_box` 不可用，应跳过或退回单参数。

### 4.4 统计在缩略图上做

长边 900 px 足够，p95 由几万像素决定，缩略不会改变它。
全分辨率算 L\* 是 102 ms/张，缩到 900 是 10 ms 量级。

**跑批时这条也是内存纪律**：全幅 PIL 136 MB，再转 BGR 又 136 MB，
本机桌面占十几 G 时两张图就能把内存吃到 OOM。`measure_pil()` 内部先缩再转。

## 5. 怎么读这条公式

固定 `L_box = 85`（背景中位）时：

| 原片主体 p95 | 该给 EV |
|---:|---:|
| 40 | +1.11 |
| 60 | +0.69 |
| 80 | +0.27 |
| 每亮 10 个 L\* | −0.21 档 |

背景再亮 10 个 L\*，再少给 0.14 档。

## 6. 两个换算尺，别用错

| 说法 | 数值 | 含义 |
|---|---:|---|
| 同一张照片内，+1 EV | **+13.9 L\*** | 物理斜率 |
| 跨照片，原片暗多少 → 多给 1 档 | **47 L\***（单看主体）/ **29 L\***（主体背景同增） | 回归斜率的倒数 |

**两者差 3–4 倍。** 因为他只补偿原片亮度差异的 **25%**，留下 75%。

独立验证：

```
从模型斜率反推保留率 = 1 + 13.9 × (−0.02108) = 0.749
直接回归实测（成品 ~ 原片）        = 0.777
差 0.028
```

两条完全独立的路径落在 0.75–0.79 这个窄带里。

**如果谁把"1 EV = 13.9 L\*"当成"原片暗 14 个 L\* 就该加 1 档"，会错 3 倍。**

## 7. 13 类算法都试过，没有一类赢

| 算法 | MAE |
|---|---:|
| **掩膜内 p95 + 盒内背景 p95（本方案）** | **0.281** |
| 掩膜内 p95 + 全图 p90 | 0.280 |
| 三参数（+ 全图均值） | 0.278 |
| 掩膜内 p95 + 盒外 p95 | 0.288 |
| 高光保护（掩膜内 p95，单参数） | 0.315 |
| 高光保护（全图 p99） | 0.343 |
| 尼康矩阵式（中央 + 高光 + 占比） | 0.363 |
| 中央重点（高斯加权网格） | 0.381 |
| 平均测光（18% 灰） | 0.389 |
| 中间调锚定（网格中位） | 0.412 |
| 常数基线（永远 +0.33） | 0.415 |

前几名彼此差 ≤0.01，在噪声内；选盒内背景是因为它有明确物理含义。
**真正的分界在 0.28 与 0.34 之间**——那是"知不知道虫在哪"的差别。

虫子中位只占画面 **2.7%**，任何网格测光测的都是背景。
这就是为什么 18% 灰平均测光（0.389）几乎等于常数基线（0.415）。

## 9. 闭环验证（100 张，不写任何照片文件）

按批次分层抽 100 张，以成品为基准做物理曝光增益 `2^(EV_pred − EV_true)`：

**方向：大动作全对**

| 要动的幅度 | 张数 | 同向 |
|---|---:|---:|
| \|EV\| <0.3 | 29 | 59% |
| 0.3–0.6 | 39 | 77% |
| **0.6–1.0** | 20 | **100%** |
| **≥1.0** | 12 | **100%** |

**幅度：无系统偏移** —— dEV 中位 −0.048，MAE 0.255，压缩比 0.895。

**主体亮度：87% 在 8 L\* 以内**（≤3 L\* 占 57%，≤5 L\* 占 69%）。

**高光：没有过曝风险** —— 接近溢出占比：成片 0.01%，按模型给 0.00%。

## 10. 硬边界：8-bit 高光饱和

内嵌预览是 8-bit。量化误差只有 0.35–0.50 L\*（模型的 1/8），不是瓶颈。
**真正的问题是高光 clip**：一旦到 255，信息永久丢失，p95 变成压在 100 上的平线。

| 主体 p95 | 张数 | 占比 | 该组 MAE |
|---|---:|---:|---:|
| <80（未饱和） | 1857 | 42.2% | 0.252 |
| 80–90 | 1362 | 31.0% | 0.255 |
| 90–95 | 673 | 15.3% | 0.276 |
| 95–99 | 403 | 9.2% | 0.356 |
| **≥99（饱和）** | **101** | **2.3%** | **0.503** |

最后一行 R² 是负的——**模型对已饱和的照片完全失效**。

处理方式：**标记，不硬修**。`L_in ≥ 96` 时输出 `saturated=1` 与警告，
让这类照片走人工。合计 11.5% 的照片 p95 ≥95，都不能全信。

## 11. 试过但无效的

| 做法 | 结果 |

| 动态范围、网格离散度、直方图偏度/峰度 | 全部输给常数基线 |

## 12. 标签里还有一层：LocalExposure2012

XMP 里 XP 有两层曝光：

```xml
crs:Exposure2012        全局，调整体        ← 大多数人只读这个
crs:LocalExposure2012   蒙版，分区微调      ← 漏了它就解释不了剩下 40% 方差
```

本项目实测：**21.5% 的照片用了局部曝光的渐变蒙版**，中位 −0.104 EV。
它的作用位置是**压暗背景 0.14 档、几乎不动主体**（中心 −0.022 / 角落 −0.136）。

**本流水线只写 `Exposure2012`，不写局部蒙版**——那是修图判断，规则化不了。
但知道它在，就不用怀疑"为什么 R² 只有 0.58"。
