# 03 · 裁切（v3，105 项）

## 1. 问题定义

不是"识别昆虫"，是**复现一个人的构图习惯**：虫体占多大、放在哪、四周留多少白。
所以输入必须是「这个人自己已经裁好的一批成品」，公式从成品反解。

## 2. 四类量（唯一允许的输入）

| # | 类别 | 变量 | 定义 |
|---|---|---|---|
| ① | 本体尺寸与位置 | `core_w core_h core_cx core_cy` | 躯干框（不含腿/触角/翅） |
| ② | 附肢范围 | `full_w full_h full_cx full_cy` | 含附肢的外接框 |
| ③ | 头部位置 | `hx hy` | 头心相对 core 中心，按 core 宽高归一 |
| ④ | 离散度 | `D = full 面积 / core 面积` | 附肢比躯干伸出去多少 |

**「足的最边缘」不是第五类**——它就是 ② 的四条边，换个说法而已。

### 各有几分用（4184 张 / 11 批 / 5 折留出）

**单组独用**（统一到 4 项口径 = 该组 2 个尺寸 + 2 个位置，项数相同才能比）：

| 只用这一组 | IoU 中位 |
|---|---:|
| ① 本体（4 项） | 0.8310 |
| ② 附肢（4 项） | 0.8330 |
| ③ 头部（仅 2 项） | 0.6519 |
| ④ 离散度 D（仅 1 项） | 0.6498 |
| ①+②（6 项） | 0.8484 |
| ①+②+方向 dx/dy（8 项） | 0.8569 |
| ①+②+③ 去 log2D（12 项） | **0.8651** |

**逐组挖掉**（从全量 0.8650 里去掉一组）：

| 操作 | IoU 中位 | 掉 |
|---|---:|---:|
| 全量（13 项） | 0.8650 | — |
| 丢 log2D | 0.8651 | ±0（零贡献） |
| 丢 head 组 | 0.8563 | **−0.0087** |
| 丢 full 组 | 0.8592 | −0.0058 |
| 丢 core 组 | 0.8624 | −0.0026 |

读法：

1. **本体框与附肢框高度冗余**——单独都能撑到 0.83，去掉任一个只掉 0.003–0.006。
   不是"一主一辅"，是**冗余备份**，真实裁切里两者一起给出。
2. **头部是唯一提供正交信息的组**：独用只有 0.652，但几何信息齐备后仍能加 0.0087。
3. `log2D` 零贡献。**本 skill 仍保留它**，因为系数是按 13 项拟合的；
   要删它必须重拟合（12 项 / 91 系数，0.8651）。不重拟合直接删会让系数错位。

⚠️ **口径陷阱（踩过）**：早先把「① 尺寸+位置（4 项）」和「② 纯尺寸（2 项）」并排比，
得出"① 远强于 ②"——那是项数差造成的假象。同口径重测，② 反而略高 0.002。
**比任何两组参数，项数必须一致。**

## 3. 公式

### 3.1 13 项特征 → 三个数

```
f1  log2D
f2  core_w
f3  core_h
f4  full_w
f5  full_h
f6  core_cx − 0.5
f7  core_cy − 0.5
f8  dx_asy = (full_cx − core_cx) / core_w
f9  dy_asy = (full_cy − core_cy) / core_h
f10 hx = (头心_x − core_cx) / core_w        （多主体/无头 = 0）
f11 hy = (头心_y − core_cy) / core_h        （同上）
f12 hx · (core_cx − 0.5)
f13 hy · (core_cy − 0.5)

设计向量 = [1] + f1..f13 + 全部两两乘积 f_i·f_j (i≤j)
        = 1 + 13 + 91 = 105 维
```

**顺序不能改**，与 `assets/data/crop_coef_v3.json` 的 105 个系数一一对应。

> v1（`insect-auto-post`）用的是另一套 9 项顺序（`ccx-0.5` 排在第 4 位），
> 它的 `crop_coef_quad.json` 里 `feat` 名字也是按 v3 顺序写的，照着复现会掉到 0.67。
> 本 skill 只有一套顺序，就是上面这个。

### 3.2 三个数 → 一个正方形

```
cx = Σ coef_cx · x
cy = Σ coef_cy · x
w  = 2 ^ (Σ coef_log2w · x)
```

框是**正方形**：原片 3:2，归一化坐标里 w == h 就等于物理上的 3:2 裁切。
只解一个尺寸量，比同时解 cw/ch 少一组自由度。

### 3.3 硬约束（顺序不可调换）

**① 绝不出界 > ② 腿到框边 ≥3% > ③ IoU 好看**

```python
pad = 0.03
need_l, need_t = full[0] - pad, full[1] - pad
need_r, need_b = full[2] + pad, full[3] + pad
need = max(need_r - need_l, need_b - need_t)
w = max(w, need, 0.05)          # ② 腿留白
if w > 1.0: w, limited = 1.0, True

x0, x1 = cx - w/2, cx + w/2
if x0 > need_l: x0, x1 = need_l, need_l + w     # 框心夹进「不切腿」可行域
if x1 < need_r: x0, x1 = need_r - w, need_r
...（y 同理）

# ① 最后夹进画布
if x0 < 0 or y0 < 0 or x1 > 1 or y1 > 1:
    limited = True; 贴边
```

画布装不下时 `canvas_limited=True`，**不许为了凑 IoU 把框缩到切腿**。

## 4. 精度

| 指标 | 值 |
|---|---:|
| 样本 | 4184 张 / 11 批次 |
| 留出 IoU 中位（按批次 5 折） | **0.8650** |
| 样本内回代 | **0.8756**（均值 0.8487，q25 0.8075） |
| IoU ≥0.80 | 73.5% |
| 框宽 MAE | 0.049（归一化） |
| 框心 MAE | 0.011 / 0.012 |
| 腿留白 ≥3% 达标 | 98.8% |
| 画布受限 | 3–4% |
| **80 张盲测（未参与调参）** | **0.9017**（均值 0.8719，<0.7 仅 3 张） |

**误差分解**（`assets/images/07-error-decomp.png`，n=4184，三种情况都重新施加硬约束）：

| 组合 | IoU | 相对基准 |
|---|---:|---:|
| 预测中心 + 预测尺寸 | 0.8650 | — |
| 预测中心 + **真值尺寸** | **0.9367** | **+7.2 pt** |
| **真值中心** + 预测尺寸 | 0.8785 | +1.3 pt |

→ **尺寸误差贡献 7.2 个点，框心只贡献 1.3 个点。瓶颈在框宽，不在框心。**
头部再准，收益也有限（消融里也只值 0.0087）。

## 5. 适用域

⚠️ 下面这组数字来自 **54 项口径（1706 张）**的分档统计，v3（4184 张）没有单独重算。
趋势可信（小虫最差），具体数值不要当 v3 的指标引用。

| 场景 | 留出 IoU（54 项口径） |
|---|---:|
| 主体适中（core_w 0.15–0.35，约 66%） | 0.8533 |
| 主体小（core_w <0.15，约 18%） | 0.8284 |
| 主体大（core_w >0.35，约 16%） | 0.8483 |
| **小虫（full_w <0.08）** | **0.5755**（17 张，1%） |
| 中虫（0.08–0.15） | 0.8277 |
| 贴边裁（pad/cw <0.15） | 0.8215 |

**唯一的系统性弱点是小虫**：虫宽占全幅 <8% 时掩膜只有 20–60 px，会明显变差。
跑批时挑出来人工看即可。

多主体（两只以上、交配对、虫群）：仍出框，但头部项关闭，且不进精度统计——
core 框横跨两只时，真值本身没有一致的构图逻辑。

v3 的分档统计是待补项：用 `refit_crop.py --csv ...` 加 `--by-size` 之类的分组即可重算，
本次未做。

## 7. 与 v1（54 项）的关系

| | v1 54 项 | v3 105 项 |
|---|---|---|
| 样本 | 1706 张 / 14 批 | 4184 张 / 11 批 |
| 特征 | 9 项（顺序不同） | 13 项 |
| 目标 | pad / rx / ry（3:2 框） | cx / cy / log2w（正方形） |
| 留出 | 0.8476 | **0.8650** |
| 80 张盲测 | 0.8497 | **0.9017** |

v1 的 54 项是 `昆虫头部目标检测` 会话的产物；v3 是后续在更大样本上的重做。
**两者不可混用**：特征顺序、目标定义、硬约束都不同。

⚠️ 但 v3 的训练集（4184）与当前范围白名单不一致，见 `references/01` §2。
